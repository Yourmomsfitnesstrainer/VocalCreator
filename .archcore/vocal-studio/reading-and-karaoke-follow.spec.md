## Purpose & Scope

Контракт десктопной шкалы и исполнения BL-006–BL-009. 14 сентября 2026 года пользователь поручил реализацию, затем отменил статические страницы: непрерывное следование остаётся, исправляется плавание букв. Требования и проверка: @docs/karaoke-reading-v1.md. Анализ аудио, достоверное слогоделение и заливка BL-003 вне задачи.

## Surface

@src/karaoke_generator/static/studio.js: drawTimeline, readingLabelLayout, readingWordsLayout, drawReadingText, renderUpcoming, renderInspector, followPosition, seek.
@src/karaoke_generator/static/studio.html и @src/karaoke_generator/static/studio.css: легенда, транспорт, инспектор, строка будущих слов и развёрнутая шкала.
Входы: неизменные ноты, интервалы, связи слов и частей, общий аудиочас. Состояния следования: off, following, suspended; play/pause независимо.

## Normative Behavior

1. При нескольких словах внутри ноты renderer MUST различать области существующих временных связей.
2. При неподписанном промежутке renderer MUST сохранять звучание и отсутствие текстовой привязки.
3. При выборе области инспектор MUST раскрывать исходную ноту и её word_id.
4. При навигации UI MUST считать исходные акустические события, сохраняя все атаки.
5. При продолжении части renderer MUST сохранять текстовую опору и знаки продолжения.
6. При рисовании подписи renderer MUST размещать её снаружи нотного прямоугольника.
7. При непрерывном следовании renderer MUST сохранять мировые координаты подписей независимо от текущего слова и горизонтального смещения.
8. При переносе букв renderer MUST повторно использовать растры на сетке физических пикселей.
9. При смене слова панель исполнения MUST сохранять высоту.
10. При запросе подробностей UI MUST раскрывать диагностику без сдвига партии.
11. При включении караоке UI MUST развернуть партию в рабочем окне и сохранить play/pause.
12. При включении караоке UI MUST разместить диапазон всех нот по высоте без автоматических вертикальных переходов.
13. При воспроизведении following контроллер MUST вычислять горизонтальную позицию по общему аудиовремени.
14. При ручном перемещении шкалы контроллер MUST перейти в suspended до явного возврата.
15. При программном перемещении контроллер MUST сохранить состояние следования.
16. При возврате к исполнению контроллер MUST восстановить following без изменения play/pause.
17. При паузе или конце записи контроллер MUST прекратить автоматическое движение.
18. При смене скорости контроллер MUST сохранить следование и аудиопозицию.
19. При возвращении фоновой вкладки контроллер MUST использовать актуальный аудиочас без очереди перемещений.
20. При выходе из караоке UI MUST восстановить обычный вид и выбранные масштабы.
21. При сильном увеличении контроллер MUST ограничить масштаб караоке для трёх секунд реального времени справа от курсора.
22. При приближении следующего слова строка «Далее» MUST показать его целиком, включая переходы без паузы.
23. При инструментальной паузе строка «Далее» MUST начинаться со следующего вступления.
24. При показе текущей части UI MUST оставить символы статусов, расшифровки — в верхней легенде и доступных подписях.
25. При первой загрузке UI MUST выключить караоке.
26. При изменении настройки UI MUST сохранить выбор караоке локально.

## Constraints & Invariants

Опора времени — 35% полезной ширины, допуск 2 CSS px вне краёв записи. Верхний запас подписей остаётся видимым; диапазон нот фиксирован для партии. Размещение меняется при изменении геометрии или масштаба, но не при каждом кадре движения.
Значения canonical_text, words, text_parts, note_text_links, labels, ID и времена сохраняются. Расписание атак и аудиобуферы не меняются из-за компоновки.
Каноническая лирика с пунктуацией доступна в обычном виде. Контекст и приблизительность обозначены явно; причины доступны в диалоге и aria-label.
Три секунды — выбранный параметр программной реализации; оценка удобства при пении остаётся за пользователем.
Строка будущих слов имеет постоянную высоту; крайне плотный текст доступен через горизонтальную прокрутку. Слова без времени остаются в полной лирике.
Временное suspended не сохраняется после перезагрузки. Контроллер перемещает внутреннюю шкалу и сохраняет фокус.

## Failure Behavior

1. При недостаточных временных связях renderer MUST сохранить исходную ноту и явно обозначить неизвестную границу.
2. При перекрытии связей renderer MUST сохранить оба слова с символом спорной границы.
3. При отсутствии текущей ноты контроллер MUST продолжить горизонтальное следование, сохраняя диапазон высот.
4. При недоступной локальной настройке UI MUST сохранить работоспособность переключателя.
5. При достижении края контроллер MUST ограничить прокрутку реальным диапазоном.
