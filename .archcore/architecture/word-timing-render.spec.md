Исторический контракт. Karaoke MP4 удалён по BL-004 14 сентября 2026 года; требования ниже больше не действуют. Общие аудио и alignment сохранены в студии.

## Purpose & Scope
Контракт JSON → ASS → MP4 для CLI, Web и ручного rerender. Акустическая точность распознавания находится за пределами этого контракта.

## Surface
- Генерация ASS: @src/karaoke_generator/subtitles.py.
- Кодирование видео: @src/karaoke_generator/renderer.py.
- Канонические данные: `lines[].words[].start/end` в @src/karaoke_generator/models.py.

## Normative Behavior
1. WHEN создаётся ASS, генератор MUST вычислить начало и конец каждого слова от абсолютных границ JSON.
2. WHEN применяется offset, генератор MUST сдвинуть только отображение слов.
3. WHEN длится пауза, генератор MUST удерживать завершённую заливку предыдущего слова.
4. WHEN начало события обрезается нулём, генератор MUST сохранить уже прошедшую часть эффекта.
5. WHEN строка переносится, генератор MUST сохранить времена каждого слова.
6. WHEN показывается preview, генератор MUST сохранить канонические границы текущей строки.
7. WHEN запускается render, renderer MUST нормализовать начало видео и аудио по декодированной шкале.

## Constraints & Invariants
- `start/end` являются единственным источником времени; поля происхождения не переопределяют ручные правки.
- ASS использует `\kt` для начала и `\kf` для длительности. Абсолютные границы округляются в сантисекунды независимо.
- Отрицательные значения `\kt` сохраняют прогресс эффекта после обрезки события у нуля.
- Offset по умолчанию равен 0; диапазон −1000…+1000 мс. Старый YAML с явным значением сохраняет его при чтении.
- Перенос JSON → ASS допускает ошибку до 10 мс без накопления; MP4 добавляет максимум один кадр и 10 мс.
- Проверка поддержки тегов опирается на реальный рендер установленного libass, а не на разбор строки ASS.

## Failure Behavior
1. IF offset неконечен или выходит за диапазон, THEN генератор MUST выдать ValueError.
2. IF канонический интервал невалиден, THEN генератор MUST выдать ValueError с текстом слова.
3. IF событие полностью завершилось до нуля, THEN генератор MUST пропустить его отображение.
4. IF FFmpeg не поддерживает libass, THEN renderer MUST выдать ошибку зависимости.

## Conformance
@tests/test_subtitles.py проверяет 250 дробных интервалов, ручные правки, перенос строк и отрицательное начало.
@tests/test_media_timing.py проверяет кадры и декодированное аудио при offset 0, −250 и +250 мс.
@scripts/verify_render_timing.py сохраняет B0/B1/B2 относительно коммита 350088c; акустическая сетка этих вариантов одинакова.
Поддержка `\kt` и `\kf` описана в [исходнике libass](https://github.com/libass/libass/blob/master/libass/ass_parse.c).
