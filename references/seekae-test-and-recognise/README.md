# Seekae — Test & Recognise (Flume Re-Work)

Постоянный английский пример EN-01 для рабочей демки VocalCreator 0.1. Пользователь предоставил файлы и 13 сентября 2026 года поручил добавить их в этот репозиторий.

| Файл | Содержимое |
|---|---|
| `audio.mp3` | Оригинальный MP3, байты не изменены |
| `lyrics-source.rtf` | Оригинальная лирика RTF, байты не изменены |
| `lyrics.txt` | Точный UTF-8 TXT, полученный из RTF через macOS textutil |
| `manifest.json` | Язык, происхождение, размеры и SHA-256 всех трёх файлов |

TXT содержит 305 канонических вхождений слов. Пример фиксирует входы; автоматические времена и ноты не являются независимой эталонной разметкой. Артист и музыкальное произведение не относятся к лицензии программного кода проекта.

Проверка файлов без сервера и моделей:

```sh
.venv/bin/python scripts/check_reference_song.py --check-files-only
```

Проверка работающей локальной студии:

```sh
.venv/bin/python scripts/check_reference_song.py --url http://127.0.0.1:8082
```

Скрипт читает файлы из этой папки; Downloads и textutil для прогона не нужны. Анализ, WAV дорожек, кеши и отчёты сохраняются локально вне Git. Расширение набора до шести треков записано в [бэклоге](../../docs/backlog.md).
