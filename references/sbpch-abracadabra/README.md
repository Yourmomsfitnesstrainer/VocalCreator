# Самое Большое Простое Число — Abracadabra

Постоянный русский пример RU-01 для VocalCreator. Пользователь предоставил файлы 14 сентября 2026 года и поручил сохранить рядом с Seekae, чтобы следующие проверки проходили на обеих песнях.

| Файл | Содержимое |
|---|---|
| `audio.mp3` | Оригинальный MP3, байты не изменены; длительность 315,26 с |
| `lyrics-source.txt` | Оригинальный `Abracadabra.txt`: UTF-16 LE с BOM и переносами CRLF, байты не изменены |
| `lyrics.txt` | TXT для загрузки: UTF-8 без BOM, переносы LF; слова, пунктуация, строки и повторы сохранены |
| `manifest.json` | Происхождение, язык, преобразование, размеры файлов и SHA-256 |

Текст содержит 323 канонических вхождения слов. Выполнено декодирование UTF-16 и сохранение UTF-8 с заменой CRLF на LF; редактирование лирики не выполнялось. Исходники в Downloads также сохранены. Артист и музыкальное произведение не относятся к лицензии программного кода проекта.

Проверить файлы обеих песен без сервера и моделей:

```sh
.venv/bin/python scripts/check_reference_song.py --check-files-only
```

Следующий полный прогон на локальной студии:

```sh
.venv/bin/python scripts/check_reference_song.py --url http://127.0.0.1:8080
```

Скрипт по умолчанию проверяет Seekae и Abracadabra с языками `en` и `ru`, записывает отдельные отчёты и общий отчёт в новый каталог `output/reference-check/<UTC-время>/`. После прогона необходимо проверить оба результата в настольном браузере. `--song abracadabra` выбирает только этот пример для отдельной диагностики.

При добавлении примера пользователь поручил отложить анализ до следующей проверки. Сейчас проверены только исходные файлы и преобразование текста; соответствие слов исполнению и акустическая точность пока не оценивались. Анализ, дорожки, кеши и отчёты остаются локально вне Git.
