# Проверка слоговой партии — 14 сентября 2026

Реализованы T1–T6 из `syllable-score-v1.md`. T7 выполнен на двух новых песнях. После просмотра пользователь подтвердил работоспособность и принял текущий результат; независимая оценка точности границ не проводилась. Утверждение «все границы акустически верны» не делается.

## Основа и сохранность

Работа начата с `769d0cc6775974fb1d708ed7ba7063b571770db6` и предоставленного локального снимка: SHA всех 150 файлов проверены до восстановления. Унаследованные изменения старого ручного редактора сохранены; общий reset/clean не применялся. Текущий diff относительно HEAD включает эту основу и не является перечнем только новых изменений.

Sputnik и Mujuice впервые прошли подготовку аудио, разделение, alignment, извлечение F0, сегментацию и синтез в отдельном локальном каталоге. Повторные проверки используют только подтверждённые результаты этих же файлов. Старые Seekae/Abracadabra не запускались через анализ. Новые MP3/RTF/TXT, результаты, ревизии и подробные отчёты находятся вне Git.

После слоговых и ручных изменений все 14 артефактов original.mp3, lyrics.txt, vocals.wav, instrumental.wav, alignment.json, melody.json и piano.wav двух песен сохранили SHA. Снимок 321 акустического события полной мелодии Sputnik до исправления CTC совпадает с финальным по id, start, end, midi, intervals и source_note_ids.

## Реальные результаты

| Показатель | Sputnik, EN | Mujuice, RU |
|---|---:|---:|
| Канонических слов/токенов | 198 | 118 |
| Исходных нот полной мелодии | 321 | 273 |
| Предложенных слогов | 237 | 214 |
| Целых элементов с неизвестной разбивкой | 3 | 12 |
| Нотных связей | 348 | 295 |
| Единиц без размещения | 8 | 52 |

Четыре RU fallback — отдельные тире. Рост числа неразмещённых RU единиц после улучшения CTC объясняется появлением отдельных слогов вместо одного неразмеченного слова. Например, в одном позднем многосложном слове пригодный F0 есть только у одного слога. Остальные доступны для коррекции; ноты для них не создавались.

Слоги маркируются как автоматические предложения. Сопоставление использует CTC того же вхождения и существующие интервалы нот; паузы не заполняются. Число нот и переходы высоты не определяют число слогов. Переназначение средней области распева сохраняет старый слог по обе стороны и упорядочивает единицы по первому активному интервалу.

Исправлена ошибка английского CTC: дефис с ID blank исключается из target forced_align, при этом исходное написание сохраняется. Слово с дефисом больше не отключает восстановление всей лирики. Проверка вызвала настоящий torchaudio forced_align.

Для Mujuice исправлено округление длины piano на один sample: только производные входы темпо выравниваются на один последний sample. Исходные WAV не изменены. Более длинное расхождение и усечённые WAV по-прежнему отвергаются. Все .25/.5/1/2× обеих песен подготовлены успешно; длительность проверена относительно исходного времени.

## Ограничения и следующий ручной просмотр

- Точность границ на слух не подтверждена автоматически. CTC score не является калиброванной вероятностью правильного слога.
- Для первого просмотра подходят Sputnik 14.4–19.8, 29.3–33.8, 148.5–150.0; Mujuice 34.1–40.1, 46.4–47.5, 184.7–185.5. Это интервалы для проверки, не акустические эталоны.
- Не все слова имеют пригодный F0, особенно в Mujuice. Эти места остаются явно нерешёнными.
- Если старая ручная ревизия относится к уже заменённой полной мелодии, она воспроизводит собственные notes/piano на 1×. Другие скорости временно блокируются, чтобы не подставлять пианино новой базы.
- Нет миграции старых ручных слов на ближайшие ноты, обучения по пользовательским правкам или подтверждённого второго голоса.

Воспроизводимый API-прогон: `scripts/check_reference_song.py --url http://127.0.0.1:8091`. Перед ним `scripts/prepare_syllable_references.py` и `--check-files-only` проверяют локальные оригиналы. Подробные JSON/XML/log и исходные хеши сохранены в локальном `VocalCreator/syllable-score-20260914/verification/`. При первоначальной передаче сервер рабочей копии и две вкладки результатов были оставлены открытыми. Следующим поручением пользователь разрешил установку в основной локальный проект, коммит/push и закрытие лишних экземпляров.
